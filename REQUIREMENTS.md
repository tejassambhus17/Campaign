Page references are printed PDF pages 1-25. R01-R58 retain the original parent IDs; decimal children below make compound requirements auditable. Parent completion requires every applicable required child. Do not infer completion from documentation, scaffolding, or a sibling row.

Classes: **Required** includes an expressly stated condition; **Optional** includes recommendations; **Conceptual** is explanatory scope. The original parent label **Mandatory** means Required. Conditional video, audience and placement support must be explicitly disclosed, not silently omitted. Status vocabulary: `NOT STARTED`, `IN PROGRESS`, `IMPLEMENTED`, `VERIFIED`, `BLOCKED`. Implementation needs code; verification needs named evidence and its limits. The initial expanded baseline recorded no verified application behavior. Current source-inspection updates below do not substitute for runtime evidence.

Implementation locations in the baseline are plans until inspected. This matrix is updated after code/evidence review; it is not a promise that pending functionality works. User-only release/configuration constraints are in [docs/DELIVERY.md](docs/DELIVERY.md), separate from PDF requirements.
